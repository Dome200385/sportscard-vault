# SportsCard Vault V0.18.1

Hotfix for the market dashboard.

- Collection value is always visible in the Collection tab.
- If no verified comps exist, the UI explicitly shows “Noch nicht berechenbar” instead of a dash.
- Market coverage and comp count are visible.
- Collection market summary now paginates through the full collection instead of only the first 200 identities.
- No AI-generated prices are introduced.

Automatic acquisition of real sold comps is intentionally the next development stage (V0.19).
