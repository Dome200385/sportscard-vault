# SportsCard Vault V0.18.0 – Market Comps

- Collection market summary based on medians of stored comparable sales.
- Per-card market endpoint with comp count, median, range and reliability threshold.
- Smart Collection now shows estimated collection value and coverage.
- Card details show comp-based valuation and recent comparable sales.
- No AI-invented prices: cards without comps remain explicitly unvalued.
- Existing manual comp endpoint remains available for adding verified sold prices.

No new Render variables or database migration are required.
